# MatOonm — telechargements

Ce depot ne contient **aucun code source** : il sert uniquement a publier
les versions installables (APK Android) de l'application interne
d'inventaire MatOonm.

## Installer

1. Va dans l'onglet **Releases** (a droite sur cette page, ou
   https://github.com/Cedric0510/MatOonm-releases/releases).
2. Telecharge le fichier `.apk` de la derniere version.
3. Sur Android, ouvre le fichier telecharge pour l'installer (autoriser
   "installer des applications inconnues" si demande, uniquement pour
   l'appli utilisee pour le telechargement).

iOS : en attente (application native prevue via l'App Store/TestFlight).
