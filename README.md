# MatOonm — telechargements

Ce depot ne contient **aucun code source** : il sert uniquement a publier
les versions installables (APK Android) de l'application interne
d'inventaire MatOonm.

## Installer sur Android (le plus simple)

1. **Sur ton PC**, garde cette page ouverte.
2. **Sur ton telephone Android**, ouvre l'appareil photo et **scanne ce QR code** :

<p align="center">
  <img src="qr-telecharger-matoonm.png" alt="QR code de telechargement MatOonm" width="260">
</p>

3. Touche le lien qui s'affiche : le fichier **MatOonm.apk** se telecharge.
4. Ouvre le fichier telecharge et touche **Installer**.
   - Si Android demande l'autorisation « Installer des applications inconnues »,
     accepte-la **uniquement pour le navigateur utilise** (Chrome, par exemple).
   - Si Google Play Protect affiche un avertissement, choisis **Installer quand meme** :
     l'appli est interne a l'entreprise et n'est pas publiee sur le Play Store.

Le QR code ne change jamais : il pointe toujours vers la **derniere version**.
Pour mettre a jour l'appli, scanne-le de nouveau et reinstalle par-dessus
(tes donnees sont sur le serveur, rien n'est perdu).
